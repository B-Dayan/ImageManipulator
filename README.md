# About
A Python-based image manipulator that runs in the console and uses the CV2 module. The program can flip, resize, or rotate an image in the same directory as itself. 
When run, the program first asks for a file name and displays the retrieved image, Next, it asks the user to select a manipulation option and requests additional information based on the selected option.
Finally, the program displays the manipulated image in a new window and asks if the user would like to manipulate the image in another way or exit the program.
